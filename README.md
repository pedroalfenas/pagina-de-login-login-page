# Página de Login
## Objetivos:
* Aprender na prática como fazer uma página de login e usar <form>
* Entender a estilização de tags internas ao login, como <input> e <label>
* Entender como funciona o blur (desfoque)

## Como adicionar no seu computador?

Abra o seu terminal e execute o comando abaixo para clonar o projeto:

```bash
git clone https://github.com/pedroalfenas/Pizzaria-Di-Napoli.git
```
